# Zone Driving Hours PWA

Standalone, single-user driving-hours tracker for Zone 1, Zone 2 and Zone 3.

- 438 timetable records embedded
- Data stored in browser localStorage on each device
- No login or shared database
- 5-week cycle
- Zone-specific duty selection by date/day type
- Overtime for late break / late finish
- Rest Day exclusion
- History and summary
